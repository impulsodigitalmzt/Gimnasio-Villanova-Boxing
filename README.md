# Villanova Boxing — Sitio oficial

Plataforma web del gimnasio **Villanova Boxing**. Incluye landing, membresías, portal del socio, CRM admin simulado, retos y tienda.

**Nota:** autenticación, pagos y CRM usan datos simulados (localStorage / cookies demo).

## Correr en local

1. `npm install`
2. (Opcional) Copia `.env.example` a `.env.local` con los usuarios demo
3. `npm run dev`

### Credenciales demo

|------|---------|------------|
