Dos mensualidades: cómo se entienden

El pago único de desarrollo construye el módulo (diseño, programación, pruebas y puesta en marcha). Eso es independiente de lo que se paga cada mes.

1) Mensualidad base · $4,500 (siempre)

Cubre que la plataforma exista y funcione en internet. El cliente no administra ni paga por separado servidores ni plataformas técnicas: eso va dentro de este cargo.

  • Servidores / hosting de la plataforma en producción.
  • Plataformas técnicas (base de datos, autenticación, despliegue, almacenamiento).
  • Supervisión técnica, corrección de fallas y soporte (horario de atención).
  • Actualizaciones de seguridad y mantenimiento preventivo.
  • Personal técnico del proveedor para operación de infraestructura (no es nómina del gym).
  • Ajustes ligeros del Arranque: textos y contenido comercial básico.

Esta mensualidad no se libera. Continúa aunque el cliente ya administre todos sus módulos.

2) Mensualidad de administración · aparte de la base

Se cobra solo si el proveedor tiene que administrar el contenido u operación de un módulo porque el cliente aún no lo hace por sí mismo (falta el panel administrador o decide no operarlo).

Ejemplo Tienda (totales ya calculados):

  • Hay tienda desarrollada, pero no hay administrador para que el gym agregue productos, precios o características.
  • El proveedor administra el catálogo → mensualidad = $4,500 + $1,200 = $5,700.
  • Se desarrolla el administrador (CRM) y el cliente lo opera → se libera el +$1,200 → mensualidad = $4,500.
  • La misma lógica aplica a Portal, CRM, Pase Digital y Retos: si el proveedor lo administra, se suma el cargo de ese módulo; si el cliente lo administra, se libera.
  • Pueden coexistir varios cargos de administración a la vez (uno por módulo que el proveedor opere).
  • La base de $4,500 siempre se mantiene.

Qué no cubre ninguna mensualidad

  • Comisiones por transacción de la pasarela de pagos (Mercado Pago u otra).
  • Número / cuenta de WhatsApp Business del gimnasio (propiedad del cliente).
  • Desarrollo de módulos nuevos (tienen pago único aparte).
  • Rediseños mayores, campañas de marketing o producción audiovisual.
  • Equipamiento físico del gym (cámaras, torniquetes, impresoras, etc.).

Lineamientos Comerciales

I. Condiciones y Ejecución

  • Horario de atención: lunes a viernes, 9:00 a 18:00 (Tiempo del Pacífico · Mazatlán).
  • Cronograma sujeto a entrega de materiales, logotipos, textos, fotos y accesos por parte del cliente.
  • Cambios fuera de alcance se cotizan por separado.

II. Pago, Garantía y Propiedad

  • Arranque: $27,500 al iniciar y $27,500 al publicar (total desarrollo: $55,000).
  • Sistema completo (precio especial): $78,250 al iniciar y $78,250 a la entrega (total: $156,500).
  • Mensualidad base: $4,500 cada mes (permanente).
  • Mensualidad de administración: solo si el proveedor opera un módulo por el cliente; se libera cuando el cliente lo administra.
  • Módulos opcionales: 50% al iniciar el módulo y 50% a la entrega (salvo acuerdo distinto por escrito).
  • Garantía técnica: 90 días naturales contra errores de programación del alcance entregado.
  • Al liquidar el 100% del desarrollo contratado de un módulo, la propiedad del código entregado de ese módulo es del cliente.

III. Infraestructura y Operación

  • La mensualidad base incluye infraestructura (servidor, base de datos, autenticación y servicios afines), soporte y mantenimiento técnico.
  • La administración de contenidos de módulos (productos, socios, retos, etc.) es un cargo aparte, solo si la realiza el proveedor.
  • Las comisiones por transacción de la pasarela de pagos no forman parte de este presupuesto técnico.
  • Se acompaña el despliegue, la configuración y la estabilización inicial de cada módulo entregado.
